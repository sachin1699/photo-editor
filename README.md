# 🎨 Browser-Based Image Editor

A modern, browser-based image editor built using **HTML**, **CSS**, and **JavaScript**. This application allows users to upload images, apply real-time filters and presets, preview changes instantly, and download the edited image—all without any external libraries or frameworks.

## 🚀 Features

- 📤 Upload images (JPG, PNG, WebP)
- 🎚️ Real-time image editing using HTML5 Canvas
- 🌟 Multiple built-in filter presets
- 🎨 Adjustable image filters:
  - Brightness
  - Contrast
  - Saturation
  - Hue Rotation
  - Blur
  - Grayscale
  - Sepia
  - Opacity
  - Invert
- 🔄 Reset image to original state
- 💾 Download edited image
- 📱 Responsive and modern UI
- ⚡ Fast client-side processing (No server required)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/browser-image-editor.git
```

### 2. Open the project

Open the project folder in **Visual Studio Code**.

### 3. Run the project

If you're using **Live Server**:

- Right-click `index.html`
- Click **Open with Live Server**

The editor will open in your browser.

---

## 🎮 How to Use

1. Upload an image.
2. Adjust filters using the sliders.
3. Apply a preset if desired.
4. Preview changes in real time.
5. Click **Reset** to restore the original image.
6. Click **Download** to save the edited image.
